## Bugun ishga olinmayapti

Wonmor ishga olmayapti. Ochiq lavozimlar yoʻq va bu sahifa boshqacha koʻrsatishga urinmaydi: bu yerda «Apply now» tugmasini topmaysiz. Wonmor — bitta asoschi yuritadigan, oʻz mablagʻi hisobidan ishlaydigan brend va u rol uchun munosib haq toʻlay olgandagina uni eʼlon qiladi.

Bugun qila oladigan ishingiz — ochiq kodli loyihalarda ishlash. Quyidagilarning hammasi haqiqiy va hozir ochiq.

## Hissa qanday qoʻshiladi

```steps
Issue tanlang :: Avval unga izoh yozing, ikki kishi bir ishni qilmasin.
Fork va branch :: Oʻz forkʼingizda ishlang, oʻzgarishni kichik va aniq qiling.
Tekshiruvlarni yurgizing :: Loyiha testlarini oʻzingizda yurgizing; CI ularni pull requestʼingizda yana yurgizadi.
Pull request oching :: Qaysi issueʼni yopishini yozing. Maintainer koʻrib chiqadi va oʻzgartirish soʻrashi mumkin.
Birlashtirish :: Qabul qilingan pull requestʼlar squash qilinadi, tarixda har oʻzgarish bitta commit boʻladi.
```

bitg har bir commitʼda Developer Certificate of Origin imzosini soʻraydi (`git commit -s`); uning CONTRIBUTING fayli birinchi pull requestʼni qadamma-qadam tushuntiradi.

## Qanday ishlaymiz

- **Yozma, asinxron.** Qarorlar uchrashuvlarda emas, issue va pull requestʼlarda qabul qilinadi. Istalgan vaqt mintaqasidan hissa qoʻshishingiz mumkin.
- **Oʻzbek, rus yoki ingliz tilida.** Issue va pull requestʼlarni uchalasidan qaysi biri sizga qulay boʻlsa, oʻshanda yozing.
- **Kichik oʻzgarishlar.** Bitta ishni qiladigan qisqa pull request kattasidan tezroq koʻrib chiqiladi.
- **Oʻlchangan daʼvolar.** Oʻzgarish biror narsani tezroq yoki aniqroq qilsa, raqamni va unga qanday erishganingizni koʻrsating.

## Savollar

**Hissa qoʻshuvchilarga haq toʻlanadimi?** Yoʻq. Bugun pullik hissa dasturi yoʻq. Bu oʻzgarsa, shu yerda eʼlon qilinadi.

**Men boshlovchiman. Yordam bera olamanmi?** Ha. bitgʼning good first issueʼlaridan biridan boshlang; ularning baʼzilari hujjat yoki soʻzlar roʻyxatidagi oʻzgarishlar boʻlib, Rust umuman talab qilmaydi.

**Oʻzbek tilini bilishim shartmi?** Yoʻq. Oʻzbek tili bitgʼning til maʼlumotlarida yordam beradi, lekin kod, testlar va hujjatlarni ingliz yoki rus tilida qilish mumkin.

**Hissalarimni rezyumemda koʻrsatsam boʻladimi?** Ha. Birlashtirilgan pull requestʼlar GitHubʼda sizning nomingiz bilan ochiq turadi.

**Suhbat yoki test bormi?** Bugun yoʻq, chunki ishga olish jarayoni yoʻq. Faqat pull requestʼlaringizga qaraladi.
