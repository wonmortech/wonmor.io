До 30 октября 2026 года проекты dtwin жили в личном аккаунте GitHub. Для одного человека и одного репозитория этого хватает. Для семейства продуктов с общей инфраструктурой, общими релизными процессами и растущим числом участников — уже нет. Поэтому мы создали организацию `dtwinuz` и перенесли в неё всё за один день.

## Аккуратный переезд

До и после каждого переноса мы считали коммиты, issues, pull requests, релизы и теги — у каждого репозитория числа совпали. Секреты переехали вместе с репозиториями. Доски проектов скопированы со всеми представлениями и значениями полей, а образы контейнеров скопированы в `ghcr.io/dtwinuz`, чтобы работающие сервисы ничего не заметили. Домен dtwin.uz подтверждён для организации.

## Одни правила для всех

Смысл организации в том, что правила перестают зависеть от того, кто создал репозиторий. Теперь в каждом репозитории:

- три команды — `core`, `maintainers` и `contributors` — с правами admin, maintain и write;
- только squash-слияния, так что история `main` читается как один коммит на изменение;
- файл `CODEOWNERS` и сгруппированные обновления Dependabot, которые ждут семь дней после выхода версии, прежде чем её предложить;
- GitHub Actions, закреплённые по полному SHA коммита, — организация теперь этого требует;
- релизные workflow, которые публикуют SBOM и build provenance и запускают сканирование Trivy.

У всех участников включена двухфакторная аутентификация. Шаблонный репозиторий — API на .NET 10, фронтенд на React и Vite, Caddy, Docker Compose и CI — позволяет начинать новый продукт сразу со всем этим.

Часть защит, например обязательное ревью в приватных репозиториях, на бесплатном тарифе GitHub недоступна. Мы отметили, где это так, а не делаем вид, что это не важно.
