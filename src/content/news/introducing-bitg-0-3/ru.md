bitg позволяет писать по-узбекски латиницей 2026 года — с ö, ğ, ş, ç и ʼ — в любом приложении и не ломает английские слова между ними. Версия 0.3, вышедшая 12 ноября 2026 года, — первая, которая охватывает все три настольные операционные системы.

## Одно ядро, три оболочки

Движок преобразования — одна библиотека на Rust с C-интерфейсом. Поверх неё у каждой системы своя тонкая нативная оболочка:

- **Windows** — метод ввода для Text Services Framework, устанавливается из MSI-пакета.
- **Linux** — два Debian-пакета: для IBus и для Fcitx5.
- **macOS** — метод ввода InputMethodKit в универсальном `.pkg`, пока в бете.

## Где взять

Пакеты есть на bitg.uz и в GitHub Releases. В Linux можно поставить из подписанного apt-репозитория, в macOS — из Homebrew tap. Заявка в winget для Windows на рассмотрении.

## Насколько точно

На открытом наборе для оценки bitg правильно преобразует 98,87% слов. Прежние 99,17% оказались завышены из-за пересечения оценочного набора с данными, на которых построен bitg; после его удаления честный результат — 98,87%. Если слово действительно неоднозначно, bitg не угадывает, а оставляет его как есть.
