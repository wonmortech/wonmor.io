bitg 0.2.0, вышедший 12 ноября 2026 года, — первая версия, которая работает не только в Windows. Рядом с установщиком для Windows в релизе два Debian-пакета:

- `bitg_0.2.0_amd64.deb` — движок для IBus, для Ubuntu 22.04+ и Debian 12+.
- `fcitx5-bitg_0.2.0_amd64.deb` — дополнение Fcitx5 для рабочих столов KDE.

К каждому пакету приложен файл `.sha256`. Код для Windows в этом релизе не изменился по сравнению с 0.1.0.

## Одно ядро, тонкие оболочки

Логику преобразования не переписывали под Linux. Она живёт в Rust-крейте с C-интерфейсом, а оболочки для Linux — тонкие обёртки над ним: движок IBus написан на C, дополнение Fcitx5 — на C++. Исправление в ядре сразу попадает на все платформы.

## Как это тестируется

На каждом pull request запускается отдельный Linux-workflow. Он поднимает настоящий `ibus-daemon`, набирает в нём текст и проверяет результат — восемь сквозных сценариев, все проходят. Кроме того, пакеты проверяются `lintian`, устанавливаются и удаляются, а для дополнения Fcitx5 проверяется, что все его символы разрешаются.

Больше всего времени ушло на две проблемы. Объект шины IBus в Python — синглтон, поэтому тест должен дождаться сокета D-Bus до его создания, иначе он ни к чему не подключится. А привязка GObject для кодов клавиш ждёт строку, а не число.

## Что ещё не готово

Пакет Fcitx5 проходит проверки сборки, но на момент выхода им ещё не набирали текст в реальном приложении, поэтому он помечен как тестовый. Пакеты RPM и Flatpak запланированы, но пока не собраны.
