# /swarm — direction card

Subject noun:      the swarm itself: named cursors that build the page, and 3D particles that build the mark
States:            blank → framed → typed → painted → stamped → reviewed → wrecked → rebuilt
Register:          entertainment on a product studio's site
Accent:            #2969FF (Wonmor cobalt, from the mark), plus one colour per agent
Type:              Wm Serif display, Wm Sans body, Wm Mono for the log and data (Latin, Latin Ext, Cyrillic covered)
Signature:         Swarm Rebuild: cursors frame, type, paint, stamp and count every block from real data;
                   the same swarm in 3D (WebGL points) forms the Wonmor mark, the 16-product constellation,
                   a timeline helix and a sphere as you scroll
Second moment:     Wreck: any visitor can knock the page down and watch the swarm put it back
Differentiators:   real products, real screenshots and real counts, built live; the visitor's cursor joins in
Deliberately off:  claiming the cursors are AI agents, invented numbers, sound, scroll-jacking,
                   backdrop-filter over moving 3D, a light theme (this page is a night scene on purpose)

Content is in the HTML from the first byte. `public/js/swarm-boot.js` only hides it when the swarm script will run,
and gives it back after 4 s if the script never arrives. `?static` and `prefers-reduced-motion` show the page at once.
